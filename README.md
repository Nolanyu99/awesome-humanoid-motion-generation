# Awesome Humanoid Motion Generation for Loco-Manipulation

> Scope: papers and projects that **generate, plan, predict, reconstruct, or expose an intermediate whole-body motion representation for humanoid loco-manipulation**, followed by tracking, control, policy learning, or data generation.

This list focuses on the motion layer between task intent/perception and low-level whole-body execution. It is not intended to cover every end-to-end VLA, teleoperation system, or controller that directly emits joint actions.

## Generative Motion Prior

### DreamControl — 2025

- **Representation / generator:** an off-the-shelf human-motion diffusion model, guided by task and spatiotemporal constraints, generates human-like whole-body reference trajectories.
- **Input → output:** text task and sparse spatial/temporal targets → whole-body human-motion reference.
- **Execution:** a task-specific RL policy is optimized in simulation using the generated motion prior, then transferred to hardware.
- **Hardware:** Unitree G1.
- **Links:** [project](https://genrobo.github.io/DreamControl/) · [arXiv](https://arxiv.org/abs/2509.14353) · [code](https://github.com/GenRobo/DreamControl)

### DreamControl-v2 — 2026

- **Representation / generator:** a transformer diffusion model trained directly in a canonicalized robot-motion space assembled from human and robot motion datasets.
- **Input → output:** text and spatiotemporal constraints → guided robot-space whole-body reference trajectories.
- **Execution:** generated references supervise downstream RL skill policies.
- **Hardware:** Unitree G1.
- **Links:** project: TBD · [arXiv](https://arxiv.org/abs/2604.00202) · code: TBD

### Humanoid-DART — 2026

- **Representation / generator:** goal-conditioned dual-branch diffusion jointly generates robot and object trajectories; an iterative augmentation loop keeps successful trajectories and relabels near misses.
- **Input → output:** target goal plus a few demonstrations/elite rollouts → goal-conditioned robot and object reference trajectories.
- **Execution:** an RL motion tracker evaluates and executes candidates in physics; successful rollouts expand the training set.
- **Hardware:** Unitree G1.
- **Links:** project: TBD · [arXiv](https://arxiv.org/abs/2606.26855) · code: TBD

## Motion Planning / Optimization

### Opt2Skill — 2024 preprint / 2025 publication

- **Representation / generator:** differential dynamic programming (DDP) produces dynamically feasible, contact-rich whole-body trajectories with state, control, and torque references.
- **Input → output:** task and contact constraints → full-body optimal trajectory.
- **Execution:** an RL policy imitates the offline trajectories and predicts joint-level targets, using torque-reference information during learning.
- **Hardware:** Digit.
- **Links:** [project](https://opt2skill.github.io/) · [arXiv](https://arxiv.org/abs/2409.20514) · code: TBD

### Physically Consistent Humanoid Loco-Manipulation using Latent Diffusion Models — 2025

- **Representation / generator:** latent-diffusion-generated human–object interaction images provide candidate contacts and robot configurations, which seed whole-body trajectory optimization.
- **Input → output:** a scene image and task decomposition/prompts → contacts/configurations → physically consistent whole-body motion.
- **Execution:** whole-body trajectory optimization enforces kinematic and dynamic consistency.
- **Hardware:** simulation only in the reported evaluation.
- **Links:** project: TBD · [arXiv](https://arxiv.org/abs/2504.16843) · code: TBD

### MotionDisco — 2026

- **Representation / generator:** LLM-guided evolutionary search discovers discrete interaction/contact programs; a sequential kinodynamic optimizer turns feasible programs into full motions.
- **Input → output:** language goal and feasibility feedback → contact plan → dynamically feasible full-body trajectory.
- **Execution:** RL policies track the discovered reference trajectories on hardware.
- **Hardware:** real humanoid robot.
- **Links:** [project](https://atarilab.github.io/motiondisco.io/) · [arXiv](https://arxiv.org/abs/2606.06139) · code: TBD

## Learned Motion Interface

### VisualMimic — 2025

- **Representation / generator:** a task-specific visuomotor policy predicts sparse keypoint commands for the root, hands, feet, and head.
- **Input → output:** egocentric images and proprioception → whole-body keypoint targets.
- **Execution:** a task-agnostic keypoint tracker, distilled with a teacher–student procedure, maps targets to robot control.
- **Hardware:** Unitree G1.
- **Links:** [project](https://visualmimic.github.io/) · [arXiv](https://arxiv.org/abs/2509.20322) · [code](https://github.com/visualmimic/VisualMimic)

### REFINE-DP — 2026

- **Representation / generator:** a transformer diffusion policy plans chunks of base-velocity and hand-pose commands; PPO fine-tunes the planner together with the controller.
- **Input → output:** task/robot state and demonstration history → high-level motion commands.
- **Execution:** a low-level RL loco-manipulation controller tracks manipulation and foot-placement commands while co-adapting to the planner.
- **Hardware:** Booster T1.
- **Links:** [project](https://refine-dp.github.io/REFINE-DP/) · [arXiv](https://arxiv.org/abs/2603.13707) · code: TBD

### MotionWAM — 2026

- **Representation / generator:** a unified motion latent is decoded into whole-body motion tokens covering locomotion, torso motion, height, foot interaction, and hand manipulation.
- **Input → output:** single-camera egocentric video, via intermediate video-world-model denoising features → whole-body motion tokens.
- **Execution:** an end-to-end real-time world-action policy runs closed-loop on the robot.
- **Hardware:** Unitree G1.
- **Links:** [project](https://dit4dit.github.io/MotionWAM/) · [arXiv](https://arxiv.org/abs/2606.09215) · code: TBD

### Whole-Body UMI — 2026

- **Representation / generator:** a task-agnostic, end-effector-conditioned whole-body motion generator learned independently from retargeted motion capture.
- **Input → output:** wrist-camera observation → diffusion-policy end-effector trajectory → whole-body reference motion.
- **Execution:** an asynchronous hierarchy combines the manipulation diffusion policy, WB-UMI motion generator, latency compensation, measured-state feedback, and a whole-body controller.
- **Hardware:** Unitree G1.
- **Links:** [project](https://wholebody-umi.github.io/) · [arXiv](https://arxiv.org/abs/2609.22829) · code: TBD

## Synthetic Motion / Data Generation

### HumanoidMimicGen — 2026

- **Representation / generator:** contact-rich whole-body skills from a few source demonstrations are adapted to new object states and interleaved with whole-body locomotion/manipulation planning.
- **Input → output:** source demonstration plus new scene/object configuration → stable, collision-free state/action demonstrations.
- **Execution:** a whole-body controller realizes generated trajectories; downstream visuomotor policies train on generated and real data.
- **Hardware:** Unitree G1; synthetic data improves reported real-world policy performance.
- **Links:** [project](https://humanoidmimicgen.github.io/) · [arXiv](https://arxiv.org/abs/2605.27724) · [code](https://github.com/NVlabs/humanoidmimicgen)

### GRAIL — 2026

- **Representation / generator:** a video foundation model synthesizes interaction video in a known 3D scene; reconstruction recovers SMPL-X human motion, articulated hands, and object 6-DoF trajectories before G1 retargeting.
- **Input → output:** 3D object asset and specified scene → synthetic interaction video → metric 4D human–object trajectories → robot trajectories/actions.
- **Execution:** task-general manipulation/locomotion trackers and egocentric RGB policies are trained on the generated data.
- **Hardware:** Unitree G1.
- **Links:** [project](https://research.nvidia.com/labs/dair/grail/) · [arXiv](https://arxiv.org/abs/2606.05160) · [code](https://github.com/NVlabs/GRAIL)

### SUGAR — 2026

- **Representation / generator:** automated video reconstruction extracts human/object motion and contact labels; a privileged RL refiner converts imperfect priors into physically feasible skills.
- **Input → output:** unstructured human video → kinematic interaction prior → refined robot skill and short-horizon commands.
- **Execution:** refined skills are distilled into a hierarchical command generator and command tracker, with no reference motion required at inference.
- **Hardware:** real humanoid robot.
- **Links:** [project](https://tianshuwu.github.io/sugar-humanoid/) · [arXiv](https://arxiv.org/abs/2605.20373) · [code](https://github.com/tianshuwu/SUGAR)
